Досье охотника H5 — приложение (PWA)

Как разместить (один раз, бесплатно):
1) Netlify Drop: зайди на https://app.netlify.com/drop, войди (бесплатно) и перетащи папку pwa целиком.
   Получишь адрес вида https://имя.netlify.app — открой его на телефоне.
2) Или GitHub Pages / Cloudflare Pages — залей содержимое папки pwa как статический сайт.

Установка:
- Android (Chrome): кнопка «Установить» в шапке или меню ⋮ → «Установить приложение».
- iPhone/iPad (Safari): «Поделиться» → «На экран „Домой“».

Персонажи хранятся в памяти устройства. Для переноса и резервной копии — «Экспорт» (файл .h5.json) и «Импорт».
